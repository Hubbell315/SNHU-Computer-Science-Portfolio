I created Travlr Getaways in CS 465 in 2026 and I’m using its MongoDB-backed trip management system for my third CS 499 enhancement. I selected this enhancement because I believe that improving an existing database lets me demonstrate data integrity, query design and how I handle changes within a working application. For the database enhancement, I addressed a problem with how trip information was stored. Prices and durations were displayed as text, which made numeric filtering less reliable. In this enhancement I added `priceCents` and `durationDays` fields while keeping the original text for display. On top of this, I added a normalized resort field, schema validation, indexes and a migration script for existing trips. The API can now filter trips in MongoDB by resort, maximum price, and maximum duration. While doing this I connected the database search to a live Angular search box that matches trip names or resorts as the user types rather than having to click clear or refresh. This enhancement supports the program outcome involving well-founded computing techniques that deliver value for both the client and business. Trip data is now more consistent and easier to query while supporting the security outcome through validated search inputs, restricted writable fields and database constraints. My earlier merge sort enhancement provides stronger evidence for the algorithms and data structures outcome, while the portfolio and accompanying narratives help demonstrate technical communication.

The most useful lesson in this enhancement was that changing a schema also meant accounting for data already in the database. My first migration updated the three existing trips - however, index creation revealed that an older, nonunique trip-code index conflicted with the new unique constraint. I checked for duplicate codes, corrected the index and reran the migration successfully. I then verified a combined resort, price, and duration query, confirmed that an invalid price returned HTTP 400 and tested the live search in the browser. These checks demonstrated the behavior with sample trips and they do not establish performance at a larger scale.
